Wenn du über das Feedback-Formular eine Rückmeldung sendest, wird sie über den Dienst Web3Forms per E-Mail an mich weitergeleitet. Du musst dafür keine Kontaktdaten angeben; ein Name ist freiwillig. Dein Feedback wird nur veröffentlicht, wenn du dem ausdrücklich zustimmst – anonym oder mit Namen, so wie du es auswählst.

Falls auf dieser Website Videos gezeigt werden, sind sie über YouTube (Google) eingebunden. Beim Aufruf der Seite werden **keine Daten an YouTube übertragen**. Erst wenn du auf ein Video klickst, wird es im erweiterten Datenschutzmodus (youtube-nocookie.com) geladen. Dabei werden Daten wie deine IP-Adresse an YouTube übermittelt.
